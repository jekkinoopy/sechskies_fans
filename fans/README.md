# 粉絲名單後台特訓｜素材包

## 直接可用素材
- `assets/titles/`：4 張標題圖，**300×30 px**
- `assets/gifs/`：4 個動畫 GIF，**480×160 px**
- `assets/gallery/`：4 張相簿來源圖，**600×412 px**（比例對應前台 150×103）
- `seed_content.sql`：跑馬燈、快訊、選單、版權、粉絲名單等種子資料

## 評分前最低資料量
- 標題圖：4 筆
- 跑馬燈：4 筆
- GIF：4 筆
- 相簿：4 筆
- 快訊：6 筆
- 主選單：2 筆
- 次選單：1 筆
- 管理登入固定帳密：admin / 1234
- 版權：1 筆
- 進站人數：1 筆設定值

## 圖片顯示尺寸
- 標題後台縮圖：300×30 px
- 相簿前台：150×103 px
- 相簿後台：100×68 px

## 建議專案放置位置
把 `assets/` 整包放進你的 `webXX/` 主目錄下。
SQL 的 image_path 已經按照這個相對路徑寫好。

## 注意
這批圖片全部是自製幾何視覺，沒有使用官方藝人照片、Logo 或其他第三方素材。
